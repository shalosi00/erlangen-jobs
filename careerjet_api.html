Erhalten Ihres API-Schlüssels

Für jede Publisher-Website benötigen Sie einen individuellen API-Schlüssel, den Sie in Ihrem Publisher-Konto erhalten können.

Querying the API

Authentifizierung

Basic authentication is used to access this API. This means you will need to add an Authorization header to each request for access. The basic auth user name is your API key, and the basic auth password is an empty string.

The format of the Authorization header is:

Authorization: Basic {credentials}

where '{credentials}' is the Base64-encoded string of the API key followed by colon.

Endpoint und Parameter

Το entry point του API είναι https://search.api.careerjet.net/v4/query και παρέχει τις παρακάτω παραμέτρους HTTP GET.

Response types

Success

A successful request will result in a HTTP 200 JSON response, whose overall structure is the following:

{
  "type": 'JOBS',
  "hits": 62,
  "message": "62 matching jobs found", 
  "pages": 4, 
  "response_time": 0.322, 
  "jobs" [List of jobs: see below]
}

Error responses

Improper requests will result in various HTTP error status codes and a minimal response body indicating the error type and details, if any. Below is an overview of the potential errors encountered:

HTTP-Code Nachricht Bemerkungen
400 Unsupported locale code The provided locale code is not supported.
403 Missing param user_ip or user_agent The request did not include the user_ip or user_agent parameters.

Location mode

Not strictly an error, but a situation that will prevent any actual search from happening. Location mode is triggered as described below:

Nachricht Bemerkungen
no matching location found No location could be found matching the provided location parameter.

Beispiel

{
  "type": "LOCATIONS",
  "locations": [], 
  "message": "no matching location found", 
  "response_time": 0.11
}
Nachricht Bemerkungen
multiple locations found Several locations matched the provided location parameter. You can then opt to pick one from the provided list locations.

Beispiel

{
  "type": "LOCATIONS",
  "locations": ["choice 1", "choice 2", "choice 3"], 
  "message": "multiple locations found", 
  "response_time": 0.11
}

Job structure

Each job is structured as follows:

{
  'title': 'Python Developer', 
  'company': 'SAT1', 
  'date': 'Wed,15 Nov 2025 19:13:43 GMT', 
  'description': 'Job description excerpt', 
  'locations': 'Stuttgart', 
  'salary': '€33000-36000', 
  'salary_currency_code': 'EUR', 
  'salary_max': xx.yy, 
  'salary_min': xx.yy, 
  'salary_type': 'Y', 
  'url': 'https://jobviewtrack.com/v2/unique link'
}

Where salary_type can be:

  • Y: yearly
  • M: monthly
  • W: weekly
  • D: daily
  • H: hourly
